# Unit 3 — Storage Variables

Storage variables live permanently on the blockchain in numbered slots.

| Concept | Description |
|---------|-------------|
| Storage slot | Each state variable gets a slot (0x0, 0x1 …) |
| `storage` | Pointer to blockchain storage — changes persist |
| `memory` | Temporary — erased after function ends |
| `calldata` | Read-only, holds function arguments |
